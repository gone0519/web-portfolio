奨学金・支援制度の種類

( Grant )

給付型奨学金

原則として返済不要

家計の状況や学業成績などを基準に支給されます。国の「高等教育の修学支援新制度」では、授業料等の減免と組み合わせて支援を受けられる場合があります。

( Loan )

貸与型奨学金

卒業後に返還が必要

日本学生支援機構（JASSO）には無利子・有利子の貸与型があります。卒業後の返還計画まで含めて、家族で検討しましょう。

( Others )

大学独自・自治体・民間

条件・募集時期はさまざま

成績優秀者向けの特待生制度、入試成績による減免、地元自治体や企業財団の奨学金など。志望校の公式サイトで確認できます。

※ JASSOの予約採用は、在籍する高校を通じて申し込むのが一般的です。時期は高校の進路指導室でご確認ください。
