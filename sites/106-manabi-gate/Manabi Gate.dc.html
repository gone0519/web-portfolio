Preparation

( 02 )

Exam
Preparation

迷わず進むための、
受験準備の地図。

入試方式の違いを知り、逆算して計画を立て、正しい教材で積み重ねる。受験準備は特別なことではなく、毎日の小さな選択の連続です。ここでは代表的な入試方式と、時期ごとの学習の目安をまとめています。

一般選抜

01学力試験

共通テスト・個別試験

学力試験の結果を中心に合否を判定する、最も受験者数の多い方式です。大学入学共通テストと各大学の個別試験を組み合わせる形が一般的です。

学校推薦型選抜

02学校長推薦

調査書・面接・小論文など

在籍する高校の校長の推薦を受けて出願する方式です。評定平均などの出願条件が設けられることが多く、日頃の学習の積み重ねが評価されます。

総合型選抜

03意欲・適性

志望理由書・面接・活動実績など

大学が求める学生像（アドミッション・ポリシー）と志願者の意欲や適性を照らし合わせて評価する方式です。早めの準備が鍵になります。

基礎固めの時期

12ヶ月前〜

学習計画の一例（目安）

教科書レベルの理解を確実にする時期。苦手分野を洗い出し、毎日の学習時間を固定して習慣化することから始めましょう。

実戦演習の時期

6ヶ月前〜

学習計画の一例（目安）

模試の結果を振り返り、志望校の出題傾向に合わせた問題演習へ。時間配分を意識して解く練習を重ねます。

総仕上げの時期

3ヶ月前〜

学習計画の一例（目安）

過去問を本番と同じ時間で解き、間違えた問題を繰り返し確認。体調管理と生活リズムも、この時期の大切な準備です。

時間管理のコツ

Planning

週単位で計画を見直す

1日の計画は詰め込みすぎず、週末に予備の時間を残しておくと、遅れが出ても立て直しやすくなります。

過去問の活用

Review

解きっぱなしにしない

点数よりも「なぜ間違えたか」を記録することが大切。ミスの傾向を把握すると、残りの時間の使い方が見えてきます。

受験準備ガイド

Guide

学費について

入学金・授業料・施設設備費などは大学や学部によって大きく異なります。金額は各大学の公式サイトに掲載されている最新の情報をご確認ください。

( Scholarship )

奨学金・修学支援

返済の必要がない給付型と、卒業後に返還する貸与型があります。日本学生支援機構（JASSO）のほか、大学独自や自治体・民間団体の制度もあります。

申込時期は高校3年の春が目安（予約採用の場合）
