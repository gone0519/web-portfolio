明陽大学 入試情報サイト
========================

■ 見かた
  start.bat をダブルクリックすると、ローカルサーバーが起動してトップページがブラウザで開きます。
  （Python が必要です。ない場合は Node.js の npx を使います）
  サーバーを止めるときは、最小化された「meiyo-site server」のウィンドウを閉じてください。

  ※ .dc.html ファイルを直接ダブルクリックして開くと、ヘッダー・フッターが読み込まれず正しく表示されません。
    必ず start.bat（またはお使いのWebサーバー）経由で開いてください。
  ※ 表示には React とフォントをインターネットから読み込むため、ネット接続が必要です。

■ ページ構成
  Admissions Site.dc.html … トップページ
  About.dc.html           … 大学紹介
  Faculty.dc.html         … 学部・学科
  Exam.dc.html            … 入試対策
  Admission.dc.html       … 入試情報・出願
  Campus.dc.html          … キャンパスライフ・オープンキャンパス
  SiteHeader.dc.html / SiteFooter.dc.html … 全ページ共通のヘッダー・フッター

■ その他のファイル
  site.css      … スマートフォン・タブレット向けの共通調整
  motion.js     … スクロールアニメーション・ページ切り替え演出
  image-slot.js … 画像枠
  support.js    … ページ表示用のランタイム（編集不要）
  images/       … 写真
  images/illust/… イラスト

■ 画像の差し替え
  images フォルダ内の画像を同じファイル名で上書きすると差し替わります。

■ 公開前に確認が必要な点
  ・日程・学費・所在地・電話番号・学長名などはサンプル／プレースホルダー（◯◯）です。
  ・資料請求・オープンキャンパス予約・お問い合わせのフォームは送信先が未設定です（デモ表示のみ）。
  ・写真・イラストの利用規約（クレジット表記の要否など）をご確認ください。
