# Handoff: 不動産売却リード獲得ランディングページ（ハウジングステップ）

## Overview（概要）
不動産売却の無料スピード査定を訴求する、1カラム縦長のリード獲得LPです。ファーストビューで「30秒・4項目のカンタン入力」を強調し、査定フォームへの送信（＝リード獲得）を唯一のコンバージョンゴールとしています。参考にした既存LP（不動産仲介の売却LP）の視覚言語を踏襲しつつ、ブランド名・コピー・数値はオリジナルの「ハウジングステップ」として作成しています。

- **ゴール**：査定フォーム送信（電話問い合わせは補助的CTA）
- **トンボ**：ネイビー基調＋オレンジCTAの信頼感のある不動産LPトーン
- **言語**：日本語

## About the Design Files（デザインファイルについて）
このバンドルの `index.html` は **依存ライブラリなしの素のHTML + CSS + バニラJS** で書かれたスタンドアロンのランディングページです。ブラウザで直接開け、VS Code でそのまま編集できます（ビルド不要）。

- スタイルは `<head>` 内の `<style>`（共通クラス `.wrap` `.g-*` `.form-row` とキーフレーム／hover／レスポンシブ）＋各要素の**インラインstyle**で構成。
- 動的挙動（CTAスクロール・フォーム送信・お客様の声カルーセル・スクロール表示）は `</body>` 直前の `<script>`（IIFE, バニラJS）にまとまっています。
- お客様の声データは `<script>` 冒頭の `VOICES` 配列で編集できます。

**このデザインを対象コードベースの既存環境（Next.js / React / Vue 等）へ移す場合** は、そのプロジェクトの確立されたパターン・ライブラリを使って再現してください。環境がまだ無ければ、この `index.html` をそのまま起点に静的LPとして拡張するのが最短です。

> フォント（Noto Sans JP / DM Serif Display）は Google Fonts を CDN 読み込みしています。オフライン運用時はローカルホスティングに切り替えてください。

## Fidelity（フィデリティ）
**High-fidelity（ハイファイ）** です。最終的な配色・タイポグラフィ・余白・インタラクションまで作り込んでおり、`index.html` はそのまま公開できる完成度です。ロジック（フォーム送信・カルーセル・スクロール表示）も実装済みです。※フォーム送信は現状デモ挙動（送信後に完了パネル表示）なので、本番では**バリデーション＋API送信＋エラー表示**を追加してください。

## Layout / Responsive（全体レイアウト）
- ページは縦1カラム。各セクションは **フルブリード（全幅）背景** ＋ 内側コンテナ `max-width: 1160px; margin: 0 auto; padding: 0 40px`（`.wrap`）。
- 主要ブレークポイント：
  - **デフォルト（PC, ≥921px）**：ヒーロー2カラム、フォーム横1列、悩み2カラム、Point/理由/Voice 3カラム、Network 2カラム、フッター4カラム。

## Interactions & Behavior（インタラクション）
- **CTAクリック → 査定フォームへスクロール**：全CTA（ヘッダー・ヒーロー・問い合わせ帯・フッター）は `#lead-form` へ `window.scrollTo({top, behavior:'smooth'})`。オフセット -12px。※`scrollIntoView` は使用しない。
- **フォーム送信**：各フォームは独立state。送信ボタンで `submitted=true` にし、成功パネルへ差し替え（本デモではバリデーション無し）。→ **本番では必須項目バリデーション・API送信・エラー表示を実装**。
- **Voiceカルーセル**：`‹ / ›` で index を ±1（6件で巡回）。ドットクリックで該当indexへ。表示は index 起点の連続3件。
- **スクロール表示アニメ**：`[data-reveal]` 要素を IntersectionObserver（threshold 0.1, rootMargin `0px 0px -5%`）で監視し、ビューポート進入時に `.in` を付与 → `animation:revealUp .6s`（`translateY(18px)→0`）。フォールバックで 2.6s 後に全要素へ `.in`。
  - ⚠ **重要（実装ノート）**：本デザインの reveal は **opacityは常に1**（`transform` のみ animate）。透明フェードにするとプレビュー/低スペック環境でアニメが停止した際にコンテンツが不可視になる不具合があったため、意図的にopacityを触らない仕様。本番でも「コンテンツが消えない」ことを最優先に。`prefers-reduced-motion` で無効化推奨。
- **hover**：CTA（浮き上がり＋輝度）、理由カード（-6px）、矢印（オレンジ化＋拡大）、select focus（オレンジ枠＋リング）。
- **ヘッダー**：sticky。
