# みおか皮ふ科・美容クリニック サイトデータ

## ファイル構成
- index.dc.html … トップページ
- Clinic.dc.html … 医院案内
- Treatments.dc.html … 診療メニュー・料金表
- Doctor.dc.html … 医師紹介・症例紹介
- Reservation.dc.html … ご予約・アクセス
- SiteHeader.dc.html / SiteFooter.dc.html … 全ページ共通のヘッダー・フッター
- motion.js … スクロール・ホバーなどのアニメーション
- image-slot.js … 画像枠（ドラッグ&ドロップで画像を入れられる仮の枠）
- support.js … 表示用ランタイム（編集不要）

## プレビュー方法
共通パーツを読み込むため、ローカルサーバーで開いてください。
VS Code の拡張機能「Live Server」で index.dc.html を開くのが簡単です。

## 編集のポイント
- 文章・色・余白は各 .dc.html 内の HTML（style 属性）を直接編集します。
- 施術一覧・料金・症例・FAQ などのデータは、ファイル下部の script 内 renderVals() の配列にまとめています。
- 画像は <image-slot> を <img src="images/xxx.jpg" style="width:100%;height:100%;object-fit:cover"> に置き換えてください。

### まだ画像が入っていない枠
点線の `<image-slot>` のまま残してあります。

- **症例写真（施術前／施術後）**… トップに2組、医師紹介ページに4組。
  医療広告ガイドライン上、症例写真は**実際の患者様の写真**で、治療内容・費用・
  リスクの記載と本人の同意が必要です。素材写真は使えません。
- **アクセスのGoogleマップ**… ご予約・アクセスページの `access-map`。
  `<image-slot>` を Googleマップの埋め込み `<iframe>` に置き換えてください。

## レスポンシブ（320px〜1920px 対応済み）
PC・タブレット・スマホの切り替えは **幅 1180px** が境目です（SiteHeader と index の
renderVals() 内 `isMobile` で判定）。以降の編集で横スクロールを出さないための決まりごと：

- `body` に `overflow-x:clip` を入れています。演出で一時的に要素が画面外へ出ても
  横スクロールバーが出ません。**この行は消さないでください。**
- `grid-template-columns:1fr 1fr` などの**グリッドの子要素には `min-width:0` を付ける**。
  付けないと中の画像枠が本来の幅を無視して膨らみ、レイアウトが崩れます
  （症例のビフォー／アフター欄がこの形です）。
- 画像枠 `<image-slot>` を囲む div には `overflow:hidden` を付ける。
  拡大演出（ケンバーンズ／ホバーズーム）が枠からはみ出さなくなります。
- スマホで1行に収めたい文字に `white-space:nowrap` を使う場合は、
  `font-size` の clamp() の**最小値**を必ず確認してください。
  最小値が大きすぎると 320px 幅ではみ出します。
- 全幅のブロックを横方向にスライドさせる演出は使いません（motion.js が自動で
  縦方向のフェードに切り替えます）。
- 診療時間表は `min-width:560px` のため、スマホでは表内を横スワイプして見る形です。
