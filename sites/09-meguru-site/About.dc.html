ABOUT MEGURU

ABOUT

「めぐる」は、投資と成果が循環する状態をつくるという意思です。獲得した顧客が次の投資余力を生み、その余力がまた次の顧客を連れてくる。その循環の設計を仕事にしています。

01 — OUR STORY

STORY

代理店の提案が、現場で機能しない。
その違和感から始まりました。

創業者の田中は、大手広告代理店で7年間、D2Cブランドの運用を担当していました。提案は通る。しかし実行段階で担当が変わり、戦略の意図が失われていく。結果が出ないのは戦略のせいではなく、戦略と実行の間に落ちるものが多すぎるからだと考えるようになりました。

2019年、提案した人間が最後まで担当することを唯一のルールとして、3名で創業しました。最初のクライアントは化粧品の定期購入ブランドで、月商800万円。1年後には4,200万円になりました。

現在38名。組織が大きくなっても、担当ストラテジストが運用の細部まで把握している状態は崩していません。受注できる案件数に上限を設けているのはそのためです。

MISSION

投資と成果が循環する状態をつくる。

一度の成功ではなく、次の投資判断ができる状態まで持っていくことを成果と定義しています。数値の根拠を共有し、意思決定の主体はクライアント側に残します。

VISION

日本のD2Cが、世界で戦える土台をつくる。

商品力のある日本のブランドが、マーケティングで負けている場面を減らしたい。国内で確立した勝ちパターンを、海外展開にも接続できる形で蓄積していきます。

02 — CORE VALUES

VALUES

VALUE 01

数字で話す

印象や経験ではなく、計測できる数値で議論します。分からないことは分からないと言います。

VALUE 02

隠さない

手数料の内訳、失敗した検証、判断を誤った経緯まで開示します。都合の悪い数値も先に出します。

VALUE 03

最後まで担当する

提案した人間が運用します。引き継ぎによる精度の低下を、構造的に起こさない体制にしています。

VALUE 04

合わない仕事は断る

私たちの知見が活きない領域では、その旨をお伝えします。受注数に上限を設けています。
