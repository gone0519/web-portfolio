ミライ進学ナビ サイトデータ
================================

■ 表示のしかた
HTMLファイルをダブルクリックしても表示されません（部品ファイルを読み込むため、Webサーバー経由での表示が必要です）。

【Windows】
  「プレビュー起動.bat」をダブルクリック → ブラウザでトップページが開きます。
  ※ Python がインストールされている必要があります。

【その他の方法】
  ・VS Code の拡張機能「Live Server」で「University Admissions.dc.html」を開く
  ・このフォルダごとWebサーバーにアップロードする

※ 表示にはインターネット接続が必要です（React・Googleフォントを読み込みます）。

■ ファイル構成
  University Admissions.dc.html … トップページ
  Programs.dc.html               … 大学・学部紹介
  ExamPrep.dc.html               … 受験対策
  Admissions.dc.html             … 入試情報・サポート
  CampusLife.dc.html             … キャンパスライフ
  Contact.dc.html                … お問い合わせ
  SiteHeader.dc.html / SiteFooter.dc.html … 全ページ共通のヘッダー・フッター
  site.css                       … レスポンシブ（スマホ表示）の調整
  anim.js                        … スクロール時のアニメーション
  support.js                     … ページ表示用ランタイム（編集不要）
  img/                           … 写真（p01〜p33.jpg）・イラスト（il-*.png）

■ 注意
  ・掲載している日程・学費・電話番号などはサンプルです。
  ・お問い合わせフォームはデモのため、実際には送信されません。
