# sowa — サイト構成

LP1枚だったものを、メイン1ページ＋下層5ページに再構成したものです。
デザイン（配色・タイポグラフィ・グレイン・アニメーション）は元のLPをそのまま引き継いでいます。

## ファイル構成

```
sowa/
├── index.html      メイン（トップ）
├── company.html    会社概要
├── service.html    事業内容
├── works.html      導入実績
├── news.html       お知らせ
├── contact.html    お問い合わせ
└── assets/
    ├── data.js     ★ 文言・データはすべてここ
    ├── style.css   デザイン（全ページ共通）
    └── site.js     共通処理（ヘッダー・フッター・演出）
```

`index.html` をダブルクリックすれば、そのままブラウザで閲覧できます。

## 編集のしかた

### 文言・項目を変える

**`assets/data.js` だけ**を編集してください。全ページがこのファイルを読み込んでいます。
配列に要素を足す／消すと、そのまま画面の項目数が増減します。

| 内容 | キー |
|---|---|
| ナビゲーション | `nav` |
| 下層ページの見出し・リード文 | `pages` |
| ヒーローの縦書きコピー | `hero.vertical` |
| コンセプト本文 | `concept` |
| 選ばれる理由 | `reasons` |
| サービス一覧（9件） | `services` |
| 事業内容の3領域 | `serviceGroups` |
| ご依頼の流れ | `steps` |
| 導入実績 | `works` |
| 数字（カウントアップ） | `metrics` |
| お客様の声 | `voices` |
| よくあるご質問 | `faqs` |
| お知らせ | `news` |
| 会社概要の表 | `profile` |
| アクセス | `access` |
| フォームの項目 | `formFields` |
| 写真スロット | `photos` |
| 電話・住所など | `company` |

### 写真を入れる

`assets/photos/` フォルダを作って画像を置き、`data.js` の `img: ''` にパスを書きます。

```js
photos: {
  office: { caption: 'オフィス風景（横位置）', img: 'assets/photos/office.jpg' },
  ...
}
```

`works` の各項目にも `img` があります。空のままだと抽象アートのプレースホルダが表示されます。

### 配色を変える

`assets/style.css` の冒頭 `:root` にある変数を書き換えると全ページに反映されます。

| 変数 | 用途 |
|---|---|
| `--ink` | 文字色・ダークセクションの背景 |
| `--paper` / `--paper-2` | 背景（明・やや暗） |
| `--sage` / `--sage-deep` | アクセントのグリーン |
| `--sand` | 補助のベージュ |
