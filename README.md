# 制作実績ポートフォリオ

業種別に制作した Web サイトのデモ 82 件を、一覧から開ける静的サイトとしてまとめたものです。

- 一覧: `index.html`
- 各サイト: `sites/<slug>/`
- サムネイル: `assets/thumbs/`

カード名は「業種＋連番」で統一しています（コーポレートサイト① / 歯医者③ / 整骨院② …）。
元のブランド名やキャッチコピーはカードのサブタイトルに出しています。

## 注意

- 掲載しているサイトはすべて**制作デモ**です。社名・店名・住所・電話番号・実績の数値は架空のものとして作られています（一括の検証はしていないため、公開前に個別確認を推奨）。
- 画像の一部は、そのサイト自身の素材が揃っていないため、同じカテゴリの他サイトの素材を流用しています。
- 画像は公開用に長辺 1600px へ縮小・再圧縮しています（680MB → 209MB）。
- 検索エンジンには載せない設定です（全ページ `noindex` + `robots.txt`）。

## 更新方法

元データから再生成します。noindex と robots.txt はビルドに含まれるので追加作業は不要です。

```
cd C:\Users\gone\portfolio
node scan-all.js        # サイト一覧データを作り直す
node build-static.js    # build/ の生成物だけを作り直す（.git と README は残る）
cd build
git add -A && git commit -m "更新" && git push
```

ローカルで確認する場合は `node server.js`（http://localhost:8082）。
こちらは元データを直接配信し、欠けている画像は配信時に差し替えます。
