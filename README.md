# 制作実績ポートフォリオ

業種別に制作した Web サイトのデモ 82 件を、一覧から開ける静的サイトとしてまとめたものです。

- 一覧: `index.html`
- 各サイト: `sites/<slug>/`
- サムネイル: `assets/thumbs/`

## カテゴリ

コーポレートサイト / 医療・クリニック / 士業・専門事務所 / 飲食 / 建設・製造 /
教育・保育 / フィットネス / 美容・サロン / 観光・宿泊 / 不動産 / 物流・運輸 / 一次産業

## 注意

- 掲載しているサイトはすべて**制作デモ**です。社名・店名・住所・電話番号・実績の数値は架空のものです。
- 画像の一部は、そのサイト自身の素材が揃っていないため、同じカテゴリの他サイトの素材を流用しています。
- 画像は公開用に長辺 1600px へ縮小・再圧縮しています。
- 検索エンジンには載せない設定です（全ページ `noindex` + `robots.txt`）。

## 更新方法

元データから再生成します。

```
cd C:\Users\gone\portfolio
node scan-all.js        # サイト一覧を作り直す
node build-static.js    # build/ に静的サイトを書き出す
```

書き出し後に `build/` で noindex の付与と robots.txt の配置が必要です。
